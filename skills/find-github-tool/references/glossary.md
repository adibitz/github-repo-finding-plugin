# Plain-language glossary

Use the right-hand column with everyday users. If a technical word is unavoidable, add its
one-line explanation the first time you use it.

| Technical | Say instead |
|---|---|
| Open source | "The code is public and free; anyone can check or improve it." |
| Repository / repo | "The project's home page for its code." |
| GitHub / GitLab / Codeberg | "Websites where software projects are published and built." |
| Stars | "Popularity: how many people bookmarked it." |
| Fork | "A copy of another project." |
| Contributors | "People who helped build it." Few people = risk it gets abandoned. |
| Commit / push / last activity | "Last update." |
| Release | "A finished version you can download." |
| Archived | "Discontinued: the authors stopped working on it." |
| Issues | "Reported problems and requests." |
| License: MIT, Apache, BSD | "Free to use, including for business." |
| License: GPL, AGPL | "Free to use, including for business. If you change it and share it (or run it online for others, with AGPL), you must share your changes." |
| License: source-available (ELv2, BSL, SSPL) | "The code is visible, but some uses (often selling it as a service) are restricted. Check before business use." |
| No license | "No license, so legally you may not be allowed to use it." |
| Self-hosted | "You run it on your own computer or server instead of someone else's." |
| Hosted / cloud / SaaS | "They run it for you; you just sign up and use it in the browser." |
| Docker / Docker Compose | "A standard way to install server software with a few commands. Needs some technical comfort." |
| CLI | "A text-only program you type commands into." |
| Package / library | "A building block programmers use inside their own software." |
| API | "A way for programs to talk to each other." |
| Dependency | "Other software it needs in order to work." |
| Vulnerability / CVE | "A known security problem." |
| OpenSSF Scorecard | "A security-practices check, scored 0–10." |
| Flathub / F-Droid / winget / Homebrew | "App stores for Linux / Android / Windows / Mac." |
| YunoHost / Umbrel / PikaPods | "Services that make running your own server apps close to one click." |
| MCP server | "An add-on that gives AI assistants new abilities." |
| Hugging Face Space | "An AI app you can try right in your browser." |
