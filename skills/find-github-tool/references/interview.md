# Interview helpers

## Must-have suggestions by category

Offer 3–5 of these as multi-select options (in plain words), plus "Something else".

| Category | Typical must-haves |
|---|---|
| Invoicing / billing | Recurring invoices · Online payments (Stripe/PayPal) · Tax/GST/VAT · Multi-currency · Quotes/estimates · Expense tracking |
| CRM / sales | Contact & deal pipeline · Email integration · Team access · Reports · Mobile app |
| Project / task management | Kanban boards · Gantt/timeline · Time tracking · Team chat/comments · Mobile app |
| Notes / knowledge base | Works offline · Sync across devices · Markdown · Sharing/collaboration · End-to-end encryption |
| Website / blog | No coding needed · Themes · SEO · Comments · Newsletter |
| E-commerce / shop | Product catalog · Payments · Inventory · Shipping · Multi-language |
| Forms / surveys | Logic/branching · File uploads · Export to spreadsheet · Embeds |
| Chat / team communication | Mobile apps · Video calls · Threads · Guest access · Encryption |
| Video calls / meetings | No account needed for guests · Screen sharing · Recording · Browser-only |
| Photos / files / backup | Automatic phone backup · Sharing · Face/object search · Encryption |
| Password manager | Browser extension · Mobile app · Family/team sharing · Self-host option |
| Analytics | Privacy-friendly (no cookies) · Real-time · Simple dashboard · GDPR |
| Accounting / bookkeeping | Double-entry · Bank import · Reports (P&L) · Multi-user |
| HR / scheduling / booking | Online booking page · Calendar sync · Reminders · Payments |
| Automation / workflows | Visual builder · Many integrations · Schedules · Self-host option |
| AI tools | Runs locally/offline · Works with my documents · Free models · GPU not required |
| Developer libraries | Language/version · License · Performance · Async support · Type definitions · Small dependencies |

## Reading the user's tech level

| Signals | Level |
|---|---|
| Talks about tasks, not technology ("make invoices", "share photos with family") | beginner |
| Mentions "server", "install", "Docker" but asks how | intermediate |
| Uses code terms (API, SDK, npm, async, CLI, license names, language versions) | developer |

When unsure, ask the tech-comfort question; it costs one click and changes the whole result.

## Defaults for "Just pick for me"

- Who: just me · Where: in the browser, or an easy desktop/phone app · Budget: free · Tech: click install
- `openSourceOnly: true`, `activeWithinMonths: 12`, `techLevel: "beginner"`
